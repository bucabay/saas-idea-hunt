# Opportunity scoring rubric

Score each candidate cluster 0-5 on all eight factors. Max 40. Anchors below — pick the anchor
you can defend with ledger rows, not the one that feels right.

Write the score table into the opportunity brief with the ledger IDs that justify each number.

---

## 1. Frequency
How many independent complainants raised it?

| Score | Anchor |
|---|---|
| 0 | 1-2 complainants |
| 2 | 5-9 |
| 3 | 10-19 |
| 5 | 20+ distinct people, across multiple incumbent tools |

## 2. Triangulation
How many independent source *types*? (review site / community / labor market / marketplace)

| Score | Anchor |
|---|---|
| 0 | one source type |
| 2 | two types |
| 4 | three types |
| 5 | three types plus a labor signal with a stated salary or fee |

## 3. Payment evidence
Is anyone demonstrably spending money on this today?

| Score | Anchor |
|---|---|
| 0 | complaints only, no spend visible |
| 2 | they pay for the incumbent that lacks it |
| 3 | recurring freelance spend found |
| 5 | a salaried role exists to do it by hand, or a BPO sells it as a service |

## 4. Workaround cost
What does the current workaround cost them per month?

| Score | Anchor |
|---|---|
| 0 | mild annoyance, no quantified cost |
| 2 | a few hours/month of one person |
| 3 | a day+/month, or a fragile spreadsheet everyone depends on |
| 5 | a full-time person, or a recurring error with financial/regulatory consequence |

## 5. Wedge narrowness
Can v1 be one feature shipped in two weeks?

| Score | Anchor |
|---|---|
| 0 | needs a platform to be useful |
| 2 | needs 3-4 features |
| 3 | one feature plus one integration |
| 5 | one screen, one job, obviously done or not done |

## 6. Buyer reachability
Can you get in front of 100 of the right buyers without paid ads?

| Score | Anchor |
|---|---|
| 0 | buyer is diffuse or anonymous |
| 2 | identifiable title, no concentrated venue |
| 3 | a searchable job title plus an active community |
| 5 | a named list you can assemble today — review authors, job posters, association directory, conference attendee list |

## 7. Incumbent-response risk (inverted — high score = low risk)
If you validate this, how fast does the incumbent ship it and zero you out?

| Score | Anchor |
|---|---|
| 0 | it is a two-sprint feature already on their public roadmap |
| 2 | easy for them, but they have ignored the request for 12+ months |
| 3 | conflicts with their architecture, pricing, or an existing partner |
| 5 | structurally can't or won't — different data model, different buyer, cannibalises a revenue line, or they've publicly declined it |

"They're lazy" scores 0. Absence of an answer scores 0.

## 8. Regulatory / domain moat
Does the boring, regulated nature of the vertical protect you?

| Score | Anchor |
|---|---|
| 0 | anyone could build it in a weekend, no domain knowledge needed |
| 2 | some domain nuance |
| 3 | meaningful domain rules; buyers require references |
| 5 | HIPAA / SOC 2 / state filing / audit-trail requirements that deter casual entrants and raise willingness to pay |

---

## Reading the total

| Total | Verdict |
|---|---|
| 32-40 | Rare. Go to Phase 4 immediately. |
| 24-31 | Worth validating. Proceed, but note the weakest factor as the thing validation must resolve. |
| 16-23 | Real pain, unclear business. Keep the ledger, keep mining. Do not build. |
| 0-15 | No. Say so plainly and move on. |

Report the total honestly. A skill that always finds a winner is a skill that finds nothing.
